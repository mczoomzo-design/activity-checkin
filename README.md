# ระบบเช็คชื่อกิจกรรมนักเรียน

เว็บสำหรับเช็คชื่อนักเรียนในกิจกรรมของโรงเรียน แอดมินสร้างกิจกรรมและตั้งรอบเช็คชื่อได้เอง (เช่น วันภาษาไทยเช็ค 1 ครั้ง, กีฬาสีเช็ค เช้า–กลางวัน–เย็น หลายวัน) แล้วส่งลิงก์ให้ครูที่ปรึกษาเช็คชื่อนักเรียนในห้องของตัวเองผ่านมือถือ

- **หน้าเว็บ**: GitHub Pages (โฟลเดอร์ `docs/`)
- **ระบบหลังบ้าน / API**: Google Apps Script Web App (โฟลเดอร์ `apps-script/`)
- **ฐานข้อมูล**: Google Sheets ที่ผูกกับสคริปต์

## หน้าในระบบ

| หน้า | ใครใช้ | ทำอะไร |
|---|---|---|
| `index.html` | แอดมิน (ต้องใช้รหัสผ่าน) | สร้าง/แก้กิจกรรม, จัดการห้องและนักเรียน, นำเข้า Excel, ส่งลิงก์/QR ให้ครู, ติดตามความคืบหน้า, รายงานและส่งออก Excel |
| `check.html?t=…` | ครูที่ปรึกษา (ไม่ต้องล็อกอิน) | เช็คชื่อนักเรียนในห้องตามรอบที่เปิดอยู่ |

## การใช้งานครั้งแรก

1. เข้าหน้าแอดมินด้วยรหัสผ่านที่ได้จากการรันฟังก์ชัน `setup` (ดูใน Execution log ของ Apps Script) แล้วเปลี่ยนรหัสที่เมนู **ตั้งค่า**
2. เมนู **นักเรียน / ห้องเรียน** → ดาวน์โหลดแม่แบบ Excel → กรอกรายชื่อ → นำเข้า (ระบบสร้างห้องให้อัตโนมัติ) หรือเพิ่มรายชื่อด้วยมือ
3. ใส่ชื่อครูที่ปรึกษาของแต่ละห้องที่ปุ่ม **แก้ไขห้อง**
4. เมนู **กิจกรรม** → สร้างกิจกรรม → เลือกวันและรอบเช็คชื่อ → บันทึก
5. หน้า **ลิงก์ครู & ติดตาม** → กด **คัดลอกลิงก์ทุกห้อง** แล้วส่งในกลุ่ม LINE ครู หรือส่ง QR Code ทีละห้อง

## ลืมรหัสผ่านแอดมิน

เปิด Apps Script editor → เลือกฟังก์ชัน `resetAdminPassword` → กด Run → ดูรหัสใหม่ใน Execution log

## แก้ไขโค้ดและอัปเดต

```bash
# ทดสอบในเครื่อง (จำลอง Google Sheets) → http://localhost:8787  รหัสแอดมิน: devpass1
node dev/server.js

# อัปเดตระบบหลังบ้าน (ใช้ deployment เดิม URL จึงไม่เปลี่ยน)
clasp push
clasp deploy -i <DEPLOYMENT_ID> -d "อธิบายการแก้ไข"

# อัปเดตหน้าเว็บ
git add -A && git commit -m "..." && git push
```

`DEPLOYMENT_ID` คือส่วนที่อยู่ใน API_URL ของ `docs/assets/config.js` (ระหว่าง `/s/` กับ `/exec`)

## โครงสร้างข้อมูลใน Google Sheets

| ชีต | เก็บอะไร |
|---|---|
| Classrooms | ห้องเรียน, ครูที่ปรึกษา |
| Students | รายชื่อนักเรียน |
| Activities | กิจกรรม, วัน, รอบเช็คชื่อ, เกณฑ์ |
| Sessions | รอบเช็คชื่อแต่ละครั้ง (วัน × รอบ) |
| Links | ลิงก์และ PIN ของแต่ละห้องในแต่ละกิจกรรม |
| Attendance | ผลการเช็คชื่อ 1 แถวต่อห้องต่อรอบ |

ไม่ควรแก้หัวตารางหรือลำดับคอลัมน์ในชีตด้วยมือ
